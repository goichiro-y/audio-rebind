# Guides

How-to documents for contributors and users (**how**).

## Conventions

- Prefer English filenames without a locale suffix, for example `install.md`.
- Japanese translations: `install.ja.md` beside the English file ([i18n.md](../i18n.md)).
- Link durable “what / why” from these guides to specs under `docs/` or `docs/specs/` instead of duplicating them.

## Starting a guide

1. Copy this checklist into a new file such as `install.md`.
2. Describe prerequisites, steps, and verification.
3. Add a one-line link from this README’s list below.
