# Language and translations (i18n)

This repository uses **English as the canonical language** for humans and coding agents.

## Rules

| Content | File naming | Language |
|---------|-------------|----------|
| Source of truth | No locale suffix (`README.md`, `docs/guides/install.md`) | English |
| Japanese translation | Same path with `.ja.md` (`README.ja.md`, `docs/guides/install.ja.md`) | Japanese |
| Other locales | Same path with `.<locale>.md` (`README.zh-CN.md`) | That locale |

## Expectations

1. Change English documents first when behavior or policy changes.
2. Update translations afterward, or open an issue noting they are stale.
3. Do not put Japanese-only requirements in English filenames.
4. Agents should treat English files as authoritative when translations disagree.

## Examples

```text
README.md                 # canonical
README.ja.md              # Japanese summary / full translation

docs/guides/install.md
docs/guides/install.ja.md
```

## Removing translations

If you do not need Japanese (or other locales), delete the `*.ja.md` files. Keep this policy file or move the same rules into `AGENTS.md` so the convention stays discoverable.
