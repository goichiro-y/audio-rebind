# Language and translations (i18n)

This repository uses **English as the canonical language** for durable docs and for coding agents.

## Rules by surface

| Surface | Language | Form |
|---------|----------|------|
| **Canonical docs** (`AGENTS.md`, `CONTRIBUTING.md`, `ROADMAP.md`, `CHANGELOG.md`, `docs/**` without a locale suffix, ADRs) | **English** is the source of truth | No Japanese dual body in the same file |
| **Root `README.md`** | Japanese **landing at the top** + English landing of the **same visitor density** | USP, audience, a compact power-state table, Quick start. English also keeps comparison / requirements / status / layout. Do **not** put Event IDs, debounce, or the WASAPI diagnosis in README — those live in `docs/`. Do **not** duplicate the rest of the README in Japanese. If the two landings disagree, English wins. Durable spec is `docs/`, not README length |
| **Japanese elsewhere** | Japanese | Optional sibling `*.ja.md` (e.g. `docs/scope.ja.md`). Must not replace English. `README.ja.md` is a pointer to the README landing, not a second full README |
| **Other locales** | That locale | Sibling `*.<locale>.md` |
| **GitHub Issues** | **Japanese + short English** | Maintainer-readable Japanese first (or primary); include a short **English** title/summary and **Acceptance** so external readers and agents still have a contract. Do not require full English prose for every Issue |
| **`docs/` / ADRs** | English in-file | **No** English-then-Japanese dual body. Add `*.ja.md` siblings only when a translation is worth maintaining; otherwise read English or keep a private Japanese note under `local/` |

## Expectations

1. Change English documents first when behavior or policy changes.
2. Update `*.ja.md` siblings afterward if they exist (or open an Issue noting they are stale). The README Japanese landing lives in `README.md` — update it in the same change as the English body when the landing facts change.
3. Do not put Japanese-only requirements in canonical English filenames.
4. Agents treat English files as authoritative when a translation disagrees.
5. Do not paste host-private detail into Issues (any language) — see [guides/local-notes.md](guides/local-notes.md).

## Examples

```text
README.md                 # Japanese + English landings (same density); details in docs/
README.ja.md              # pointer to README.md#日本語 (old links)

docs/scope.md             # English only (canonical)
docs/scope.ja.md          # optional Japanese sibling — not required

docs/decisions/0007-….md  # English ADR — no in-file Japanese dual column
```

Issue body sketch:

```markdown
## 概要（日本語）
…

## English summary
…

## Acceptance
- [ ] …
```

## Removing translations

If you do not need Japanese (or other locales), delete the `*.ja.md` files. Keep this policy file (or the same rules in `AGENTS.md`) so the convention stays discoverable.
