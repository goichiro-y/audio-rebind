# Language and translations (i18n)

This repository uses **English as the canonical language** for durable docs and for coding agents.

## Rules by surface

| Surface | Language | Form |
|---------|----------|------|
| **Canonical docs** (`README.md`, `AGENTS.md`, `CONTRIBUTING.md`, `ROADMAP.md`, `CHANGELOG.md`, `docs/**` without a locale suffix, ADRs) | **English** is the source of truth | No full Japanese body inside the same file |
| **Japanese translations** | Japanese | Sibling files only: `*.ja.md` (e.g. `README.ja.md`, `docs/scope.ja.md`). Optional; must not replace English |
| **Other locales** | That locale | Sibling `*.<locale>.md` |
| **GitHub Issues** | **Japanese + short English** | Maintainer-readable Japanese first (or primary); include a short **English** title/summary and **Acceptance** so external readers and agents still have a contract. Do not require full English prose for every Issue |
| **Root `README.md` only** | English + **optional short Japanese** | After the English intro (or key sections), a **brief** Japanese summary block is allowed. Do **not** duplicate the whole README in-file. Fuller Japanese lives in [`README.ja.md`](../README.ja.md) |
| **`docs/` / ADRs** | English in-file | **No** English-then-Japanese dual body in one file. Add `*.ja.md` siblings only when a translation is worth maintaining; otherwise read English or keep a private Japanese note under `local/` |

## Expectations

1. Change English documents first when behavior or policy changes.
2. Update `*.ja.md` afterward, or open an Issue noting they are stale.
3. Do not put Japanese-only requirements in canonical English filenames.
4. Agents treat English files as authoritative when a translation disagrees.
5. Do not paste host-private detail into Issues (any language) — see [guides/local-notes.md](guides/local-notes.md).

## Examples

```text
README.md                 # canonical English (+ optional short JA blurb)
README.ja.md              # fuller Japanese summary / translation

docs/scope.md             # English only (canonical)
docs/scope.ja.md          # optional Japanese sibling — not required for every doc

docs/decisions/0007-….md  # English ADR — no in-file Japanese dual column
```

Issue body sketch:

```markdown
## 概要（日本語）
…

## English summary
…

## Acceptance
- [ ] …
```

## Removing translations

If you do not need Japanese (or other locales), delete the `*.ja.md` files. Keep this policy file (or the same rules in `AGENTS.md`) so the convention stays discoverable.
